#  КиноБаза — менеджер коллекции фильмов

Приложение на PyQt5 для ведения личной коллекции фильмов: добавление,
редактирование, удаление, поиск, просмотр постера, воспроизведение
трейлера (аудио), экспорт списка. Интерфейс собран в Qt Designer.

##  ТЗ

- Хранение фильмов в локальной БД SQLite (2 таблицы: `genres`, `movies`).
- CRUD-операции над фильмами и жанрами.
- Поиск по названию и фильтрация по жанру.
- Отображение постера выбранного фильма (QLabel + QPixmap).
- Воспроизведение аудио-трейлера (QMediaPlayer).
- Стандартные диалоги (QMessageBox, QFileDialog, QInputDialog).
- Горячие клавиши и обработка кликов мышью (двойной клик по таблице).
- Две формы: главное окно и диалог добавления/редактирования фильма.

##  Технологии

- Python 3.10+
- PyQt5 5.15
- SQLite3 (stdlib)
